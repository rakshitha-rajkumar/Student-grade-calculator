# Student Grade Calculator

A beginner-friendly Python project that calculates a student's total marks, average, and grade.

## Features

- Takes student's name
- Takes marks for three subjects
- Calculates total marks
- Calculates average
- Displays the grade

## Technologies Used

- Python

## How to Run

Run the `grade_calculator.py` file using Python.

## Grade System

- 90 and above → A+
- 80–89 → A
- 70–79 → B
- 60–69 → C
- 50–59 → D
- Below 50 → F

## Project Purpose

This project was created to practice Python basics such as variables, user input, arithmetic operations, and conditional statements.
